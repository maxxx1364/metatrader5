# MetaTrader 5 — Claude Connector

محیط توسعهٔ آنلاین برای پروژهٔ اتصال Claude به MetaTrader 5.

## GitHub Codespaces

این مخزن تنظیمات یک محیط Node.js 22 را در `.devcontainer/devcontainer.json` دارد. Codespaces همان مخزن GitHub را استفاده می‌کند؛ مخزن دیگری لازم نیست.

1. با حساب GitHub که به این مخزن دسترسی دارد وارد شوید.
2. از **Code → Codespaces → Create codespace** یک محیط روی شاخهٔ `arena/dd86d4a0-metatrader5` بسازید. ساخت و مصرف Codespaces بسته به سهمیه و تنظیمات حساب ممکن است هزینه داشته باشد.
3. اسکریپت `.devcontainer/setup.sh` وابستگی‌های پروژه را نصب می‌کند. اگر محیط را پیش از افزودن کد ساخته‌اید، بعد از انتقال فایل‌ها این دستور را در ترمینال Codespaces اجرا کنید:

   ```bash
   bash .devcontainer/setup.sh
   ```

4. پس از اضافه شدن کد و تنظیم متغیرهای محیطی موردنیاز، برنامه را اجرا کنید:

   ```bash
   cd connect-claude-to-metatrader-5
   npm run dev -- --hostname 0.0.0.0 --port 3000
   ```

5. پورت **3000** برای پیش‌نمایش برنامه فوروارد می‌شود. آن را بدون احراز هویت و تنظیمات امنیتی مناسب، عمومی نکنید.

اسکریپت نصب، هم پوشهٔ `connect-claude-to-metatrader-5` و هم فایل‌های پروژه در ریشهٔ مخزن را پشتیبانی می‌کند. اگر هنوز `package.json` وجود نداشته باشد، محیط بدون خطا ساخته می‌شود تا کد بعداً اضافه شود.

## انتقال پروژه از ویندوز

برای جلوگیری از مشکلات دسترسی Git در ویندوز، می‌توان فایل‌های پروژه را به‌صورت ZIP و بدون اطلاعات محرمانه در گفتگوی Arena پیوست کرد تا به همین مخزن اضافه شوند. پوشه‌های `node_modules`، `.next`، `.git` و فایل‌های `.env` حاوی رمز را وارد نکنید؛ فایل‌های سورس، `package.json`، `package-lock.json` و تنظیمات غیرمحرمانه را نگه دارید.

متغیرهای محیطی واقعی را در فایل محلی و نادیده‌گرفته‌شده توسط Git، مانند `.env.local`، یا در تنظیمات Secrets مربوط به Codespaces قرار دهید. مقادیر واقعی رمزها و کلیدها را commit نکنید.

## محدودیت اتصال به MetaTrader 5

Codespaces محیط لینوکسی است و ترمینال ویندوزی MetaTrader 5 را مستقیماً اجرا نمی‌کند. بخش وب و API را می‌توان اینجا توسعه داد؛ برای اتصال به متاتریدر، پل ارتباطی باید روی ویندوز یا یک محیط سازگار اجرا شود. اتصال این پل به Codespaces نیاز به پیکربندی جداگانه و دسترسی امن دارد و صرفاً با ساخت Codespace برقرار نمی‌شود.
